# Calculadora em Python
## Projeto para aprendizado em python
## Status: Funcionando
## Feito em python 3.12.4
## ---------------------

### Lógica do código
O usuário envia 2 inputs
o código checa se são números:
    Se sim, ele retorna o número
    Se não, ele pede outro input

Então, o código pede uma operação matemática, entre:
- Soma(+)
- Subtração(-)
- Multiplicação(*)
- Divisão(/)
(se o usuário enviar outra coisa que não é essas operações, o código pede outro input)
e depois, faz a operação

### Observações importantes:
Eles estão separados em 2 funções, que o código principal chama
---------------------------
Usei o isdigit() para evitar o uso de try/except, já que era possível fazer isso em menos linhas
---------------------------
Coloquei o desafio de fazer o código inteiro em apenas 30 linhas
